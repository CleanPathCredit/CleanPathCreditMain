# Backlink Outreach Pack — White-Hat Only

**Date:** 2026-06-04
**Rule for everything here:** earned/relationship/editorial links only. **No** bought links, PBNs, "$X for N backlinks" gigs, link farms, comment spam, or exact-match anchor stuffing. For a YMYL credit-repair domain, a bad link profile is an existential risk (manual action → deindex). These tactics are all safe.

> **Anchor text:** keep it mostly **branded** ("Clean Path Credit"), **naked URL** (cleanpathcredit.com), or **generic** ("learn more," "their San Antonio page"). Avoid repeating exact-match anchors like "credit repair san antonio" — that pattern is a spam signal.
